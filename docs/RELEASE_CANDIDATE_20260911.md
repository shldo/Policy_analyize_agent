# 研究辅助 Demo 发布候选

## 发布定位

这是需人工核对来源的政策研究辅助 Demo，不是无人审核的政策决策系统。
当前没有指定公网服务器或域名；代码合并、可部署交付不等于公网发布成功。

## 稳定配置

保留 BM25 + 向量 + RRF + cross-encoder、结构感知 Parent–Child、6000 token 上下文、8 Parents/每文档5、`reranker_top_k + original`。允许有依据部分回答，未评估覆盖不能标完整。

默认关闭 Controlled Retrieval、compound retrieval、claim binding；P2 仍为可选对照，不以局部 EGC 提升替代稳定性证据。这里的“稳定版”是当前已验证行为组合，不宣称数学意义上的最优质量。

## 本次必修

- production 在数据库连接前验证 APP_SECRET 不短于32字符且不是已知示例前缀、关闭 debug、启用数据库。
- production 默认拒绝注册，防止匿名创建账号消耗模型预算。现有账户登录不受影响。初始账号应在隔离、受控环境创建；不要在公网临时开放注册。
- APP_SECRET 长度校验不能证明随机性，须由操作者生成独立强随机值。
- `.env.production.example` 固定稳定配置与关闭注册；真实 secret 不提交。

## 部署交付与验收门槛

1. 明确服务器、域名、访问人群；小范围受邀演示优先。不要采购或自选云账户。
2. 目标使用独立数据库/持久卷，先备份，迁移020；禁止直接修改冻结评测库。
3. 填写独立APP_SECRET、数据库密码；当前Compose的默认数据库密码仅供本地，公网部署必须替换。数据库不公开端口。
4. 导入获准公开的PDF与索引、准备tokenizer和模型缓存、以私密方式配置运行时模型；不要公开settings.json。
5. 当前Caddyfile只监听HTTP :80。公网需要目标域名的TLS反向代理、入口限流、并发/模型预算限制；这些尚未配置，不得直接把本地端口暴露公网。
6. 真实验收登录、Direct/Agent、历史刷新、引用页码、错误反馈及权限，再切流量。若失败回退代码与配置，不删除数据库卷。
